# 安装指南

## 安装插件步骤
1. 把ZIP文件下载到自己电脑上。
2. 启动Blender。
3. 在文件菜单中，点击Edit，选择Preferences（用户设置）
4. 选中 Add-ons，在最右上角找到下箭头图标，点击。
5. 选择最后一项“Install from Disk... ，找到你在第一步时下载到自己电脑上的ZIP文件，
6. 在最下面找到按钮“Install from Disk”,按下，安装插件完成！

## 确认插件启动：
1. 在Blender文件菜单中，点击Edit，选择Preferences（用户设置）。
2. 选中 Add-ons，在顶部找到搜索框，输入Seaway Shrinkwrap Help Tools。
3. 查看插件是否启动。
4. 如果已经启动，你会在3D View的右边sideBar（快捷键"n"）中看到“SWHT”。

祝你使用愉快！
